- Shape: none 0, xs 4, sm 8, md 12, lg 16, xl 28, xxl 36, full 999, cover 24.
- Motion durations: short 120, medium 240, long 400, extraLong 700 ms. Springs: gentle/standard/bouncy/snappy/reduced.
- Type scale: display 43/45, title 30/33, heading 22/26, body 16/24, label 13/18, micro 10/14 (existing `type`).
- Default seed: `#B8F0B0`. Default scheme: dark. Default palette style: tonal-spot.

## Contrast ratios

- Body text on surfaces uses M3 onSurface/onBackground roles; enforced to 4.5:1 minimum in `enforceContrast`.
- Measured (default green seed, dark): inkMuted 10.80:1, inkFaint 6.44:1 on background, inkFaint 4.84:1 on surfaceMuted, accentInk on accent 11.89:1 (from v1.1 report, retained).
- Light mode also passes via tone enforcement.

## Measured fps

- Not measured in this environment (no device). Wavy progress scrubber not added; standard slider used (fallback per spec).

## Lyrics

- Resolver order: sidecar .lrc → ID3 USLT/SYLT → none.
- ID3 reader reads only header + tag bytes via ranged reads; handles v2.3/v2.4 encodings (ISO-8859-1, UTF-16 with BOM, UTF-8); unknown/malformed frames skipped.
- Offset persisted per track in MMKV; survives restart.
- Could not test on device (no MP3 with embedded tags available in this environment).

## Favorites

- Data layer: expo-sqlite table `favorites` keyed by file URI/path (content URI or path), with title, artist, album, duration, artwork, added_at. Idempotent upsert via ON CONFLICT.
- Sort: recently added (default), title, artist.
- MusicLibraryContext.favorites now derived from sqlite rows (by URI match), so existing heart toggles and Home/Library reflect sqlite.
- Heart button uses `library.toggleFavorite` (track-based), accessibilityLabel changes with state.
- Unavailable handling: rows kept on rescan (no silent delete); UI marks "Unavailable" — not yet wired to a rescan check (partial).
